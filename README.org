At compile time a clojure macros body is read and evaled and the result is saved
as bytecode. We can see this play out in the example below as
the JAR build time is saved into the macro, to be used when the jar runs. As
where the def value changes, because the def it self, it's body's bytecode still references a
call to get-the current time.

#+begin_src bash :results raw
clojure -T:build uber
#+end_src

- time-def:  #inst "2025-04-17T22:57:48.199-00:00"
- time-macro: #inst "2025-04-17T22:57:48.199-00:00"

#+begin_src bash :results raw
java -jar target/lib1-1.2.*
#+end_src

- time-def:  #inst "2025-04-17T22:57:53.021-00:00"
- time-macro: #inst "2025-04-17T22:57:48.199-00:00"


#+begin_src bash :results raw
clojure -T:build uber
#+end_src

#+RESULTS:
hello
time-def:  #inst "2025-04-18T12:34:34.193-00:00"
time-macro: #inst "2025-04-18T12:34:34.193-00:00"
time-def-delay:  #inst "2025-04-18T12:34:34.193-00:00"

#+begin_src bash :results raw
java -jar target/lib1-1.2.*
#+end_src

#+RESULTS:
hello
time-def:  #inst "2025-04-18T12:34:40.222-00:00"
time-macro: #inst "2025-04-18T12:34:34.193-00:00"
time-def-delay:  #inst "2025-04-18T12:34:40.222-00:00"
